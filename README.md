# 420

A research repository for robotics exploration, navigation, and planning.

## Overview

This repository is currently under development.

The project focuses on autonomous robot navigation and exploration, including topics such as:

* Global exploration planning
* Local motion planning
* Sparse / topological map representation
* Long-horizon navigation
* Reinforcement learning for robot navigation
* Quadruped robot experiments
